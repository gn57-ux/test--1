# Feature 3: exhibits-and-interaction — 任务列表

## 版本
v1

## Feature / Spec 路径
specs/3.exhibits-and-interaction/

- [ ] T-001: 创建展品数据文件（五件展品的编号/名称/故事/深度区间/强调色）｜验证：数据文件导出五条完整记录，字段齐全，类型检查通过｜复杂度：S
- [ ] T-002: 依据已确认的 Stitch/设计输入实现 ExhibitFactory 与五件展品；若用户明确批准无设计稿降级，则采用基础几何体组合；按数据定位到场景中｜验证：实现与确认的视觉依据一致，滚动场景可依次看到五件外观不同的展品，位置与数据 depthRange 一致｜复杂度：L
- [ ] T-003: 展品资源加载失败降级为基础几何体占位｜验证：模拟资源加载失败场景，展品仍以占位几何体显示，无黑屏或报错中断｜复杂度：S
- [ ] T-004: 展品浮动/缓慢旋转动画与局部光效，接入 reduced-motion 降低幅度｜验证：默认模式下展品持续浮动旋转；开启减少动态效果后动画幅度可观察地降低｜复杂度：M
- [ ] T-005: 桌面端 InteractionManager（raycaster hover/click）+ 视差控制器，含高亮/减速旋转/光标状态切换｜验证：鼠标悬停展品出现高亮与光标变化，点击触发选中事件；移动鼠标可见轻微镜头视差｜复杂度：M
- [ ] T-006: 移动端点击交互（tap 打开/空白区域或关闭按钮收起），不依赖 hover｜验证：移动视口下点击展品打开卡片，点击空白或关闭按钮收起，无 hover 依赖代码路径｜复杂度：S
- [ ] T-007: 故事卡片组件（玻璃效果/内容渲染/单例显示/关闭按钮/Esc 键关闭/aria-label）｜验证：点击展品打开对应卡片内容正确；打开新卡片时旧卡片自动关闭；键盘 Esc 可关闭；辅助功能审查工具无明显缺失的可访问名称｜复杂度：M
- [ ] T-008: 展品与故事卡片的集成联调（与 Feature 1/2 的场景与滚动系统对接）｜验证：完整滚动流程中五件展品与卡片交互均按预期工作，控制台无报错｜复杂度：M

## 依赖
- 依赖 Feature 1、Feature 2 完成。

## 风险
- 五件展品的几何体组合工作量较大（T-002 标记为 L），若视觉细节要求提高可能需要拆分为每件展品单独任务，届时需重新评估 Task 数是否超出默认范围。
- raycaster 交互在移动端与桌面端行为差异较大，需分别测试避免事件冲突（如 touch 触发 click 两次）。
