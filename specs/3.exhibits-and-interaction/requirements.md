# Feature 3: exhibits-and-interaction — 展品与交互

## 概述
实现五件展品的 3D 呈现、数据驱动的故事内容、悬停/点击视觉反馈、桌面端视差与移动端点击交互，以及故事卡片 UI。

## 版本
v1

## 用户故事
- 作为访客，我依次滚动会看到五件不同的展品，每件都有独特造型与光效。
- 作为桌面端访客，鼠标经过展品时展品高亮并减慢旋转，光标变为可交互状态；点击后弹出故事卡片。
- 作为移动端访客，点击展品即可打开故事卡片，无需依赖悬停。
- 作为访客，同一时间只会看到一张故事卡片，可以方便地关闭它。
- 作为使用键盘的访客，我可以用键盘关闭故事卡片。

## 功能需求
- F-001：系统应显示五件不同的 3D 展品（纸飞机/旧磁带/旧钥匙/拍立得照片/微型宇航员），使用基础几何体组合或本地 GLTF 模型，不依赖运行时外部模型服务。（对应 PRD F-003）
- F-002：展品信息（编号、名称、故事、视觉参数）由本地 JSON/TS 数据文件统一管理，展示逻辑不硬编码在多个组件中。（对应 PRD F-004）
- F-003：展品需具备悬停/点击高亮、缓慢旋转、浮动动画与局部光效。（对应 PRD F-005）
- F-004：桌面端：鼠标移动产生轻微镜头视差；鼠标经过展品时展品高亮并减慢旋转，光标变为可交互状态；点击展品显示对应故事卡片。（对应 PRD 4.3）
- F-005：移动端：点击展品打开故事卡片；再次点击空白区域或关闭按钮收起卡片；不依赖 Hover。（对应 PRD 4.3）
- F-006：故事卡片使用半透明深色玻璃效果，显示展品编号/名称/故事，不遮挡整个 3D 场景，支持关闭，同一时间只能打开一张。（对应 PRD 4.3）
- F-007：展品模型或纹理加载失败时使用基础几何体占位，不能黑屏或阻塞页面。（对应 PRD F-008 部分）
- F-008：reduced-motion 状态开启时，展品旋转/浮动动画幅度降低。（对应 PRD 7.可访问性）

## 非功能需求
- 故事卡片关闭按钮与展品交互元素需具备明确的可访问名称（aria-label 等）。
- 故事卡片可通过键盘（如 Esc）关闭。

## 验收标准
- AC-001：用户能够依次看到五件不同展品。（对应 PRD AC-003）
- AC-002：每件展品均可打开对应故事卡片，卡片内容与展品一一对应。（对应 PRD AC-004）
- AC-003：桌面端具有鼠标视差和悬停反馈（高亮/减速旋转/光标变化）。（对应 PRD AC-005）
- AC-004：移动端可通过点击完成全部展品交互（打开与关闭卡片）。（对应 PRD AC-006）
- AC-005：展品模型/纹理加载失败时显示基础几何体占位，不出现永久黑屏。（对应 PRD AC-010）
- AC-006：同一时间最多一张故事卡片处于打开状态。（对应 PRD 4.3 派生）
- AC-007：故事卡片可通过键盘关闭。（对应 PRD 7.可访问性）

## 依赖
- 依赖 Feature 1（scene-foundation：SceneManager、reducedMotion、deviceCapability）。
- 依赖 Feature 2（opening-and-scroll-camera：depthProgress，用于确定各展品所在深度区域的可见性/激活状态）。
