# Feature 2: opening-and-scroll-camera — 开场与滚动镜头

## 概述
实现开场标题体验与滚动驱动的镜头下潜系统：标题淡出、镜头随滚动平滑潜入、环境色随深度渐变、右侧深度指示器，并支持 reduced-motion 降级。

## 版本
v1

## 用户故事
- 作为访客，我打开页面看到标题与引导文案，开始滚动后标题淡出、镜头进入水下。
- 作为访客，我滚动页面时镜头平滑下潜，不会有突兀的跳跃感。
- 作为访客，我能通过右侧深度指示器感知当前潜入深度。
- 作为启用减少动态效果的访客，镜头运动幅度与速度降低但功能不受影响。

## 功能需求
- F-001：页面初始显示接近黑色的深蓝背景与开场标题/引导文案；开始滚动后标题逐渐淡出。（对应 PRD 4.1）
- F-002：页面滚动位置应驱动镜头下潜深度，镜头运动需平滑插值，不能直接跳跃。（对应 PRD F-002）
- F-003：环境颜色应随深度从浅蓝逐渐过渡到深蓝黑。（对应 PRD 4.1）
- F-004：页面右侧应显示简洁的下潜深度数值，使用等宽字体。（对应 PRD 4.1、5.2）
- F-005：reduced-motion 状态开启时，镜头动画强度（插值速度/视差幅度）应降低。（对应 PRD 7.可访问性）

## 非功能需求
- 镜头插值计算需在每帧预算内完成，避免掉帧。

## 验收标准
- AC-001：打开页面后能看到开场标题。（对应 PRD AC-001 部分）
- AC-002：滚动页面时镜头能够平滑下潜，无跳跃。（对应 PRD AC-002）
- AC-003：深度指示器数值随滚动实时更新。（对应 PRD 4.1 派生）
- AC-004：减少动态效果模式下镜头动画降低但滚动仍可正常驱动深度变化。（对应 PRD AC-011 部分）

## 依赖
- 依赖 Feature 1（scene-foundation）提供的 SceneManager、reducedMotion 状态。

## 已确认决定
- 深度值与滚动进度的映射函数（如百分比 vs 米数）由 design.md 定义，默认使用与总滚动高度成比例的相对深度百分比。
