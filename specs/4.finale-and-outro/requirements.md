# Feature 4: finale-and-outro — 海沟展厅与结尾

## 概述
实现页面底部的海沟展厅：场景变暗、发光水母/粒子效果、最终文案、项目信息与"返回海面"按钮。

## 版本
v1

## 用户故事
- 作为访客，滚动到页面底部时看到场景逐渐变暗、发光水母环绕最终文案。
- 作为访客，我能看到项目名称、制作说明与作品集/GitHub 链接预留位置。
- 作为访客，点击"返回海面"后页面与镜头平滑回到初始状态，可以重新体验。

## 功能需求
- F-001：用户滚动到页面底部后进入最深区域，场景逐渐变暗，远处出现发光水母，水母/粒子围绕最终文案缓慢移动。（对应 PRD 4.4）
- F-002：底部显示最终文案（诗句文案）。（对应 PRD 4.4）
- F-003：底部提供"返回海面"按钮、项目名称、制作说明、GitHub/作品集链接预留位置。（对应 PRD 4.4、F-006）
- F-004：点击"返回海面"后，页面平滑滚动至顶部，镜头回到初始位置。（对应 PRD 4.4）

## 非功能需求
- "返回海面"按钮需具备明确可访问名称，可键盘触达（focus + Enter/Space 触发）。

## 验收标准
- AC-001：滚动到底部后显示最终文案和水母或粒子效果。（对应 PRD AC-007）
- AC-002："返回海面"能够将页面与镜头恢复至开场位置。（对应 PRD AC-008）

## 依赖
- 依赖 Feature 1（scene-foundation：SceneManager、reducedMotion）。
- 依赖 Feature 2（opening-and-scroll-camera：depthProgress、resetToTop 接口）。

## 已确认决定
无。
