# Feature 1: scene-foundation — 任务列表

## 版本
v1

## Feature / Spec 路径
specs/1.scene-foundation/

- [x] T-001: 使用 Vite + TypeScript 初始化项目脚手架，建立 HTML UI 层与 Canvas 层分离的目录结构｜验证：`npm run dev` 启动后页面显示空白 Canvas + HTML 容器，无控制台报错｜复杂度：S
- [x] T-002: 实现 SceneManager 基础场景（相机/渲染器/灯光/雾/渲染循环）｜验证：本地运行可见深蓝雾效背景与渲染循环持续运行｜复杂度：M
- [x] T-003: 实现漂浮颗粒与上升气泡粒子系统｜验证：场景中可见持续运动的颗粒与气泡，帧率无明显下降｜复杂度：M
- [x] T-004: 接入 EffectComposer + Bloom 后期处理，效果强度可配置｜验证：发光元素有柔和辉光，文字/UI 区域不受影响｜复杂度：M
- [x] T-005: WebGL 支持检测与静态降级页面｜验证：手动关闭/模拟 WebGL 后显示静态背景+标题+说明文字，无黑屏或报错｜复杂度：S
- [x] T-006: 加载状态 UI 与资源加载生命周期挂钩｜验证：首次进入页面短暂显示加载界面后正常过渡到场景｜复杂度：S
- [x] T-007: 响应式适配（resize/DPR 上限）与移动端粒子/精度降级 + reduced-motion 状态基础设施｜验证：切换桌面/移动视口粒子数量与像素比按预期变化；系统开启"减少动态效果"时 `reducedMotion` 状态触发订阅回调｜复杂度：M
- [ ] T-008: 场景销毁与资源释放（几何体/材质/纹理/事件监听）｜验证：路由离开或调用 dispose 后，Three.js Inspector/内存快照显示无残留几何体与监听器｜复杂度：S

## 依赖
无。

## 风险
- Bloom 后期处理在低端移动设备上可能影响帧率，需要与 T-007 的设备能力降级联动测试。
- WebGL 检测库版本差异可能导致误判，需在多浏览器手动验证。
