---

当前没有独立测试框架或 `test` 脚本。每个代码 Task 至少运行 `npm run build`，它同时执行 TypeScript 检查和 Vite 生产构建；涉及视觉、交互或响应式行为时，再按对应验收标准进行浏览器人工验证。

来自 PRD 第 9 节验收标准（AC-001 ~ AC-012）的关键行为，应作为未来测试/QA 依据，例如：
- 滚动驱动镜头下潜的平滑性（AC-002）
- 五件展品均可依次浏览并打开对应故事卡片（AC-003、AC-004）
- 移动端可通过点击完成全部展品交互（AC-006）
- 资源加载失败时显示替代内容，不出现永久黑屏（AC-010）
- "减少动态效果"模式能够正常工作（AC-011）
- 浏览器控制台不存在持续性错误或资源泄漏警告（AC-012）

不要声称未实际执行的浏览器视觉验证已经通过。引入测试框架后再补充自动化测试命令。
